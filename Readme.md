# AWS CI/CD Pipeline using Jenkins and Docker

## Project Overview

This project demonstrates an end-to-end CI/CD pipeline using AWS EC2, Jenkins, Docker, GitHub, and Linux.

## Technologies Used

- AWS EC2
- Jenkins
- Docker
- GitHub
- Linux

## Architecture

Developer → GitHub → Jenkins → Docker → AWS EC2

## Pipeline Workflow

1. Source code pushed to GitHub
2. Jenkins pulls latest code
3. Docker image is built
4. Container is deployed
5. Application is served on AWS EC2

## Benefits

- Automated deployment
- Faster delivery
- Reduced manual effort
- Consistent releases
